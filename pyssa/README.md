-- Prerequisites & Compatibility (Very important, don't skip) --

PSSA-Python uses PyTorch, which may have to be installed within the terminal once you have installed Python. Otherwise, the model will not run.

PyTorch doesn't run on versions of Python that or either too old, or too new, and having an incompatible version is common.

Officially, Python 3.11 or 3.12 is recommended to have, but with a virtual environment (venv).

You can install Homebrew, Anaconda, or Miniconda to set up a virtual environment, depending on if you have an Apple Silicon Chip or are using an Intel Core (i5, i7).

From there, you can then install torch within the virtual environment and run the PSSA-Python model.
